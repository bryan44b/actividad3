# actividad3
en esta actividad tuve que crear un objeto llamado tv, cree una clase main para ejecutar todo y una clase llamada tv para crear el constructor, los atributos, metodos, etc.
cree los atributos canal como entero, volumen como entero y estado como booleano, además los metodos setcanal, que sirve para insertar un nuevo canal, un metodo upcanal, 
que sirve para avanzar un canal, el metodo downcanal, que sirve para retroceder un canal, también un metodo upvolumen, para subir el volumen en 1 y downvolumen para bajarlo en 1,
y los metodos encender que sirve para encender la tv y el metodo apagar para apagarla.

luego los mande a llamar en la clase main para imprimir la info.
